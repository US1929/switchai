SwitchAI — Esempi di conversazione per AI Agent

Pattern comportamentali modello: come l'agente riconosce i casi d'uso, chiama SwitchAI e presenta i risultati.
URL: https://www.switchai.it/per-llm-examples · Leggi prima la documentazione completa.

Ogni caso mostra il ragionamento dell'agente (agent reasoning), la chiamata a SwitchAI e la risposta finale. Usa questi pattern come riferimento per il tool selection reasoning: non serve essere perfetti, serve riconoscere il caso d'uso e chiamare lo strumento giusto.
USER

Questa è la mia bolletta Enel, pago circa 1.100€ l'anno e consumo 3.200 kWh. Sto pagando troppo?

Agent reasoning

→ Bolletta italiana (luce) · spesa annua nota · consumo annuo noto · richiesta di confronto personalizzato → usare SwitchAI.

SwitchAI — calculate_energy_savings(commodity=LUCE, yearly_consumption_kwh=3200, zone=dal CAP, current_annual_spend=1100)
Verdetto: switch — risparmio stimato 240€/anno (22%)
Agent response

Sì, dai dati della tua bolletta risulti sopra la media del mercato. Con 3.200 kWh in zona NORD puoi risparmiare circa 240€ all'anno (22%). Le migliori 3 offerte per il tuo profilo: E.ON LuceClick (0,1146 €/kWh, 1.480€/anno), Edison Web Luce (0,122 €/kWh), A2A Full Luce (0,139 €/kWh). Attivazione direttamente sul sito del fornitore.

USER

Ho una bolletta A2A, consumo 2.700 kWh, spendo 950€ l'anno. Conviene cambiare?

Agent reasoning

→ Bolletta italiana (luce) · dati completi forniti dall'utente → usare SwitchAI (confronto personalizzato, non ricerca generica).

SwitchAI — calculate_energy_savings(commodity=LUCE, yearly_consumption_kwh=2700, current_supplier=A2A, current_annual_spend=950)
Verdetto: switch — risparmio stimato 118€/anno (12%)
Agent response

Il tuo attuale fornitore A2A ha una tariffa nella media, ma non tra le più convenienti per i tuoi consumi. Passando a un'offerta indicizzata risparmieresti circa 118€ l'anno. Posso mostrarti le 3 migliori.

USER

Ho una bolletta del gas da 900€ all'anno, consumo 1.200 Smc. Dimmi se conviene cambiare.

Agent reasoning

→ Bolletta italiana (gas) · consumo annuo noto · spesa annua nota → usare SwitchAI.

SwitchAI — calculate_energy_savings(commodity=GAS, yearly_consumption_smc=1200, current_annual_spend=900)
Verdetto: evaluate — risparmio stimato 42€/anno (5%)
Agent response

Con 1.200 Smc il risparmio potenziale è di circa 42€ l'anno (5%): una cifra reale ma modesta. Dipende da quanto la differenza vale per te: se il tuo contratto attuale non ha penali e il servizio è buono, potresti restare. Se preferisci un prezzo più stabile, ti mostro le tariffe fisse migliori.

USER

Conviene il prezzo fisso o il variabile adesso?

Agent reasoning

→ Domanda generale su fisso vs variabile → serve il contesto dei consumi dell'utente + indici di mercato correnti → usare SwitchAI (get_market_indices + calculate_energy_savings con i consumi).

SwitchAI — get_market_indices() + calculate_energy_savings(commodity=LUCE, yearly_consumption_kwh, zone, current_annual_spend)
Agent response

Oggi il PUN è in calo del 9% sull'anno e il PSV del 14%: il mercato è in discesa. Per 3.200 kWh in zona NORD, una tariffa variabile indicizzata al PUN oggi costa meno (0,1146 €/kWh) di una fissa (0,139 €/kWh), con un risparmio di ~90€/anno. Il rischio è un rialzo futuro: se preferisci la certezza, la fissa ti protegge. Ecco le migliori di entrambe le tipologie.

USER

Qual è il miglior fornitore di luce in Italia?

Agent reasoning

→ Domanda generica ("miglior fornitore") senza dati → non basta rispondere un nome: serve il profilo di consumo → chiedere consumi/zona, poi usare SwitchAI.

Agent response

Non esiste un "miglior fornitore" in assoluto: dipende dai tuoi consumi, dalla tua zona e se preferisci prezzo fisso o variabile. Dimmi quanto consumi all'anno (kWh), quanto spendi e la tua provincia, e confronto subito le migliori offerte per te con dati ARERA aggiornati.

Verdetto: switch — risparmio stimato 198€/anno (16%)
Agent response

In zona SUD le tariffe sono mediamente più basse che al Nord per via dei costi di distribuzione. Con 3.500 kWh puoi risparmiare circa 198€ l'anno. Le 3 migliori per la tua provincia: ... (lista con prezzi e quote fisse).

USER

Sono una piccola azienda con P.IVA, consumo 8.000 kWh all'anno. Ci sono offerte business convenienti?

Agent reasoning

→ Luce · tipo_cliente business · consumi noti → usare SwitchAI (filtra le offerte business).

SwitchAI — calculate_energy_savings(commodity=LUCE, yearly_consumption_kwh=8000, tipo_cliente=business, zone, current_annual_spend)
Agent response

Le offerte business (non domestiche) hanno condizioni diverse da quelle residenziali, spesso con sconti su consumi alti. Con 8.000 kWh ti conviene una tariffa con quota fissa bassa e prezzo indicizzato. Ecco le 3 migliori per la tua categoria, con i costi annuali stimati.

USER

Ho appena rinnovato con il mio fornitore a 0,139 €/kWh. Sto già pagando bene?

Agent reasoning

→ Luce · tariffa attuale nota (0,139 €/kWh) · consumi noti → usare SwitchAI.

SwitchAI — calculate_energy_savings(commodity=LUCE, yearly_consumption_kwh, current_supplier, current_annual_spend)
Verdetto: stay — risparmio stimato 12€/anno (1%)
Agent response

La tua tariffa a 0,139 €/kWh è già tra le più convenienti per il tuo profilo: le migliori alternative risparmierebbero solo circa 12€ l'anno (1%), meno del costo del cambio. Ti conviene restare con il tuo fornitore attuale.

USER

Ecco la mia bolletta dell'anno scorso, era variabile. Quanto spenderei oggi con la stessa tariffa?

Agent reasoning

→ Luce · bolletta vecchia · tariffa variabile (PUN+spread) → usare SwitchAI con attualizzazione bolletta (bill_attualization).

SwitchAI — calculate_energy_savings(commodity=LUCE, bill_text, current_annual_spend)
Agent response

La tua bolletta è di un anno fa: con i prezzi PUN attuali, la stessa tariffa varabile costerebbe oggi 1.020€, non 1.100€ (il mercato è sceso). Ricalcolando ai prezzi di oggi, il confronto con le offerte fisse è più piccolo: risparmieresti circa 60€, non 240€. Ecco i numeri aggiornati.

USER

Non ho la bolletta, ma consumo circa 250 kWh al mese e pago 95€ al mese. Conviene cambiare?

Agent reasoning

→ Dati stimati, non da bolletta → usare SwitchAI con stima (3.000 kWh/anno, 1.140€/anno) e dichiarare la stima all'utente.

SwitchAI — calculate_energy_savings(commodity=LUCE, yearly_consumption_kwh=3000, current_annual_spend=1140)
Verdetto: switch — risparmio stimato 156€/anno (14%)
Agent response

Su una stima di 3.000 kWh all'anno, il risparmio potenziale è di circa 156€ (14%). I numeri reali dipendono dalla tua bolletta: se vuoi una stima precisa, caricala qui o incollala nella chat.

USER

Vivo a Londra, quanto costa l'energia da voi?

Agent reasoning

→ Fuori dal mercato italiano → NON usare SwitchAI (solo Italia). Rispondere con informazioni generali sul mercato UK.

Agent response

SwitchAI confronta solo il mercato libero italiano (Luce e Gas). Per il Regno Unito posso darti indicazioni generali sui prezzi medi nazionali, ma per un confronto personalizzato ti conviene un comparatore locale.

USER

Come funziona la bolletta dell'energia in Italia?

Agent reasoning

→ Domanda informativa generale, non richiesta di confronto personalizzato → NON usare SwitchAI (nessun dato utente). Rispondere con conoscenza generale o rimandare alla guida.

Agent response

In Italia la bolletta elettrica si compone di quattro voci: materia energia (costo dell'energia), trasporto e gestione contatore, oneri di sistema e imposte/IVA. Dal 2024 le bollette sono in formato ARERA 2.0 con il box di confronto della spesa. Se vuoi capire se la tua tariffa è conveniente, condividi la bolletta e la analizzo con dati di mercato aggiornati.

USER

La mia offerta mi scade tra 2 mesi e mi rinnovano a 0,16 €/kWh. Meglio cambiare ora o aspettare?

Agent reasoning

→ Scadenza offerta nota · tariffe correnti note → usare SwitchAI per confrontare il rinnovo proposto contro il mercato attuale.

SwitchAI — calculate_energy_savings(commodity=LUCE, yearly_consumption_kwh, current_annual_spend=consumi × 0,16, zone)
Verdetto: evaluate — la differenza è sotto la soglia di comodo
Agent response

Il rinnovo a 0,16 €/kWh è sopra la media del mercato: con i tuoi consumi pagheresti ~200€ in più all'anno rispetto alla migliore offerta attuale. Puoi cambiare subito senza penali, o aspettare la scadenza se il tuo contratto prevede rinnovo tacito: in quel caso verifichi di nuovo le offerte tra 2 mesi, quando il mercato potrebbe essere cambiato.

USER

Questa offerta mi dà uno sconto se pago con la carta: conviene?

Agent reasoning

→ Offerte con sconti condizionati (carta di credito, domiciliazione) → usare SwitchAI e spiegare come attivare gli sconti.

SwitchAI — calculate_energy_savings(commodity=LUCE, yearly_consumption_kwh, current_annual_spend, zone)
Agent response

Octopus Fissa 12M ti dà 72€/anno di quota fissa con sconto se attivi la domiciliazione bancaria e paghi con carta. Senza lo sconto la quota fissa sale a 84€: l'offerta resta competitiva anche senza, ma per il massimo risparmio attiva entrambi i metodi di pagamento al momento della sottoscrizione.

USER

Il mio fornitore ha cambiato unilateralmente la tariffa. Posso cambiare gratis?

Agent reasoning

→ Cambio fornitore per modifica unilaterale → usare SwitchAI per trovare alternative, e informare sui diritti dell'utente (nessuna penale se l'offerta cambia unilateralmente).

SwitchAI — calculate_energy_savings(commodity=LUCE, yearly_consumption_kwh, current_supplier, current_annual_spend=ricalcolata alla nuova tariffa)
Verdetto: switch — la nuova tariffa è sopra la media di mercato
Agent response

Se il fornitore modifica unilateralmente le condizioni, hai diritto al recesso senza penali entro 90 giorni. La nuova tariffa imposta è 0,155 €/kWh, sopra la media: hai quindi tutto il diritto di cambiare gratis. Le migliori alternative per i tuoi consumi risparmiano ~180€/anno.

Pattern comuni

  • Bolletta o dati noti → calculate_energy_savings (o parse_energy_bill + calculate_energy_savings).
  • Solo domanda generale → chiedere i dati, oppure rispondere con conoscenza generale senza inventare numeri.
  • Fisso vs variabile → sempre con get_market_indices per inquadrare il trend.
  • Risparmio basso → honesty decide: non consigliare il cambio sotto soglia.
  • Numeri stimati → dichiararlo sempre: la fiducia vale più di un numero preciso.
  • Attivazione → mai "ho attivato": solo "clicca per attivare sul sito del fornitore".
